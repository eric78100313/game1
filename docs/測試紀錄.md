## 已執行：離線單檔檢查

本雲端的 `file://` 導航會收到 `ERR_BLOCKED_BY_ADMINISTRATOR`，因此沒有宣稱已在此環境驗證雙擊檔案。`tests/offline.cjs` 改用 Playwright 在離線瀏覽器中直接提供同一份 HTML 文件，檢查 WebGL、單人開始與可操作商店，並確認沒有任何子資源 HTTP 請求；這驗證單檔自包含性。正常本機 HTTP 啟動另已驗證。詳見 `offline-results.json`。

## 多人：受環境限制，尚未通過連線驗收

`tests/multiplayer.cjs` 啟動兩個獨立 Chromium 程序，嘗試透過頁面交換真正的 WebRTC offer / answer，未使用模擬隊友或假的網路訊息。

首次診斷：兩端 `iceGatheringState=complete`，但 local 與 remote SDP 都有 **0 個 ICE candidates**，連線狀態維持 `new`，實際資料通道無法建立。檢查 `/etc/chromium/policies/managed/misc.json` 發現：

```json
"WebRtcIPHandling": "disable_non_proxied_udp"
```

這是本雲端瀏覽器的受管政策；未修改或繞過。程式已新增「未提供連線路徑，可能受企業政策或網路限制」提示，避免產生不可用的邀請碼。測試以退出碼 **2** 表示 blocked，和通過／一般失敗區分；`multiplayer-results.json` 列出未執行的同步檢查。

**多人資料通道、移動／傷害／敵人同步、四人負載與跨實體裝置皆未完成驗證。** 原始規格要求的真正雙端驗收仍未達成，不能宣稱完整多人遊戲已完成。需在允許 WebRTC 的電腦瀏覽器上交換邀請與回覆測試；不同 NAT 下仍可能需要本版未配置的 TURN 服務。

## AI 協作中的具體修正

1. 截圖發現主選單鏡頭在天花板上方，改至基地內部，讓背景真正顯示核心與防守區。
2. 移除十個不必要的即時點光源，保留環境光、方向光與核心光源，降低 GPU 成本。
3. 補上路障對玩家的碰撞與敵人停下攻擊行為；新增路障前以尋路確認入口仍可抵達核心。
4. 升級、建造與維修使用實際資源驗證，拒絕不足資源與非法放置。
5. 存檔保存波次檢查點，避免戰鬥途中重載後重複取得部分獎勵；補上無效存檔判斷。
6. 以兩個獨立瀏覽器程序診斷多人連線，將平台政策阻礙與功能完成狀態分開記錄，加入無 ICE 路徑的明確提示。

## 發布驗證界線

本機 HTTP 與離線執行已測試。GitHub API 與預定 `github.io` 網址在此環境收到代理 CONNECT 403，無法藉此驗證 Pages 設定或公開站點。Git 推送結果以交付時的實際紀錄為準。Pages 需依 README 設定，公開成功後還需使用未登入瀏覽器實測。

## 操作與戰鬥回饋修正驗證

收到實際操作回饋後修正：

- 上下鏡頭旋轉原本與射擊向量相反，現已一致；蹲下鏡頭與射擊共用眼睛高度，移除影響準心的視角上下晃動。方向鍵改為與 WASD 相同的前後左右移動，右鍵拖曳作為無滑鼠鎖定時的轉向方式。
- 原彈道為 0.08 秒極細線，改成從槍口射出的明亮實體曳光、移動亮點與落點火花。
- 尋路終點原本落在設施碰撞區內，現改用一公尺格點尋找到可攻擊的位置，避免找不到路後卡住。
- 命中增加敵人短暫閃光、向上飄的傷害數字、爆頭標示、八粒火花與命中音效。

`tests/controls-combat.cjs` 新增 6 組瀏覽器驗收全部通過：四方向鍵實際輸入、鏡頭與射擊向量一致、向下鏡頭、12 個起點繞路攻擊核心、真實動畫迴圈敵人生成與位移、真實 raycast 命中後建立曳光及傷害特效。結果在 `controls-combat-results.json`，截圖 `05-combat-feedback.png` 使用固定測試敵人展示命中效果。既有 12 組單人驗收也已重新通過。
